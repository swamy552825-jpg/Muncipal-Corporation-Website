Municipal Corporation Complaint Portal

A web-based complaint management system developed using Python and Flask. It helps citizens report civic issues and allows administrators and workers to manage and resolve complaints.

Features

- Citizen Portal: Submit complaints and track their status.
- Admin Portal: View complaints and assign work to workers.
- Worker Portal: View assigned complaints and submit completion reports.
- Complaint Tracking: Monitor complaint progress.

Technologies Used

- Python
- Flask
- HTML
- CSS
- SQLite

Project Structure

- "app.py" – Main Flask application
- "templates/" – HTML pages
- "static/" – CSS and other static files
- "requirements.txt" – Python dependencies

How to Run

1. Clone this repository.

2. Create and activate a Python virtual environment.

3. Install dependencies:
   
   "pip install -r requirements.txt"

4. Run the application:
   
   "python app.py"

5. Open "http://127.0.0.1:5000/" in your browser.
